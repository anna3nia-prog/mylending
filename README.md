# Рабочая версия

Одностраничный лендинг онлайн-курсов по нейросетям с формой заказа и юридические страницы.

- `index.html` — главная страница;
- `agreement.html` — публичная оферта;
- `privacy.html` — политика конфиденциальности;
- `refund.html` — условия оплаты, предоставления доступа и возврата;
- `consent.html` — согласие на обработку персональных данных;
- `assets/` — стили, скрипт меню и формы заказа, шрифт Onest (SIL OFL 1.1).

Форма заказа ничего не отправляет: после проверки полей показывается блок оплаты с неактивной кнопкой «Оплатить». Кнопка включается после подключения платёжного сервиса.

Сборка не нужна: это статические файлы, их можно разместить на любом хостинге (GitHub Pages, Netlify, обычный веб-сервер).

Локальный запуск: `python3 -m http.server 8000` и открыть http://localhost:8000.

## Публикация на GitHub Pages

Адрес сайта: https://anna3nia-prog.github.io/rabochaya-versiya/

GitHub Pages публикует ветку `gh-pages`. Её не нужно править вручную: при каждом изменении в `main` workflow `.github/workflows/publish-site.yml` копирует содержимое `main` в `gh-pages`, и сайт обновляется через 1–2 минуты.
